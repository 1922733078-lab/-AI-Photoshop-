# 整图变化率 C：完整数值表（含阈值敏感性）

定义：C = |{(x,y): ‖O(x,y)−I(x,y)‖₂ > τ}| / (W×H)。O=输出图像，I=基准图像；二者统一重采样到**基准图像尺寸**的网格（LANCZOS 插值）；τ 为变化阈值（0–255 标度）。复现：仓库根目录运行 `python3 analysis/change_rate.py`（依赖 PIL、numpy），输出 `analysis/change_rate_results.json`。
